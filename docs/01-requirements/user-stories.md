# User Stories

This document specifies user stories across customer, administrator, and operations roles.

---

## 1. Customer User Stories

- **US-CUST-01**: *As a new customer*, I want to create an account using my mobile number and verify it via SMS OTP so that I can securely manage my orders.
- **US-CUST-02**: *As a returning customer*, I want to sign in with my email/password or OTP and stay signed in safely so that I don't have to re-enter credentials repeatedly.
- **US-CUST-03**: *As a customer*, I want to save multiple delivery addresses and mark one as default so that I can checkout quickly.
- **US-CUST-04**: *As a customer*, I want to search products by title or category with typo tolerance so that I find relevant items even if I misspell words.
- **US-CUST-05**: *As a customer*, I want to filter products by price, brand, rating, and size so that I quickly narrow down options to my preferences.
- **US-CUST-06**: *As an anonymous shopper*, I want to add items to my cart before logging in and have them automatically merged when I log in so that I don't lose my selections.
- **US-CUST-07**: *As a customer*, I want to apply a coupon code in my cart and see instant discount breakdown and total savings before initiating checkout.
- **US-CUST-08**: *As a customer*, I want to pay securely via UPI, NetBanking, or Credit/Debit card and receive immediate order confirmation via Email and WhatsApp.
- **US-CUST-09**: *As a customer*, I want to track my order status in real time and see carrier tracking links so that I know exactly when my package will arrive.
- **US-CUST-10**: *As a customer*, I want to request a return for a delivered product within 7 days by uploading a photo of the item so that I can get a refund if the item does not fit.

---

## 2. Merchandiser & Marketing User Stories

- **US-MKT-01**: *As a merchandiser*, I want to create and organize product categories, upload high-resolution images, and define variant options (size/color) so that products are displayed appealingly.
- **US-MKT-02**: *As a merchandiser*, I want to schedule future product launches and promotional flash sales with automatic start and end dates so that marketing campaigns activate without manual midnight intervention.
- **US-MKT-03**: *As a marketing manager*, I want to configure coupon codes with maximum usage limits, minimum spend requirements, and customer restrictions so that we run profitable promotions without coupon abuse.

---

## 3. Warehouse & Operations User Stories

- **US-OPS-01**: *As a warehouse manager*, I want to view real-time stock levels across warehouse bins and record physical stock adjustments with reason codes so that inventory balances remain strictly reconciled.
- **US-OPS-02**: *As a warehouse picker*, I want to generate daily order pick-lists grouped by warehouse zone and print shipping labels so that orders are packed and dispatched swiftly.
- **US-OPS-03**: *As an inspection specialist*, I want to inspect returned packages, mark the condition of goods (Restockable vs Damaged), and approve or reject refunds so that our return policy is upheld.

---

## 4. Customer Support & Finance User Stories

- **US-FIN-01**: *As a customer support agent*, I want to look up an order by customer phone number or order ID and view the complete audit timeline so that I can resolve customer inquiries on the first call.
- **US-FIN-02**: *As a finance manager*, I want to download daily sales, GST tax summaries, and gateway fee reconciliation reports so that month-end books are closed accurately.
